# Skill de Auditoría y Roadmap (3OX)

## Auditoría Inicial
- Al iniciar o retomar el proyecto, realiza un escaneo obligatorio (`ls -R`) para mapear archivos.
- Actualiza `docs/technical/architecture_map.md` con las dependencias y routers detectados.

## Roadmap Dinámico (SMART)
- Cada iteración debe proponer y registrar mejoras en `docs/MASTER_ROADMAP.md`.
- Las tareas deben ser: Específicas, Medibles, Alcanzables, Relevantes y Temporales.

## Trazabilidad de Cambios
- Mantener `docs/MASTER_ROADMAP.md` y `docs/DOCUMENTACION_MAESTRA.md` sincronizados tras cada ciclo operativo.
